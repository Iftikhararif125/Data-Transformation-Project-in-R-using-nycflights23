Exploring Flight Data with the nycflights23 Package: A Data Transformation Project in R
This post dives into the nycflights23 package in R to explore its flight data. Let's get started! ✈️

The nycflights23 package bundles several related datasets:

flights: Flight records, including delays and destinations

airlines: Carrier codes paired with airline names

airports: Location details for airports

weather: Hourly weather observations at NYC airports

planes: Information on individual aircraft

With the data in hand, we'll move on to data transformation, relying mainly on the dplyr package. Part of the broader tidyverse ecosystem, dplyr is a go-to toolkit for data manipulation, offering functions to filter, select, arrange, mutate, and summarize data.
